# 商店購入

::: info UI 専用機能
本ページの機能は UI 層で実装されています。詳細は[始めに](../newbie.md#このドキュメントについて)を参照してください。
:::

商店購入タスクは、緑チケット商店と黄チケット商店をワンクリック周回のキューに入れ、実行間隔に従って自動で購入します。購入範囲は [ミニゲーム](./tools.md#ミニゲーム) の対応機能と同じです。本タスクは [FP獲得と交換](./credit.md) とは別です。

## 商店

同時に選択でき、緑チケット商店、黄チケット商店の順に実行します。

### 緑チケット商店

- 1 階は全部購入。
- 2 階はスカウト券と求人票を購入。

### 黄チケット商店

黄チケットを少なくとも 258 枚所持していることを確認してください。

## 実行間隔

1 つのタスクで間隔は共通です。商店ごとに前回成功時刻を記録し、設定に表示します。

| オプション | 説明 |
| :--- | :--- |
| 毎回 | タスクキューを実行するたびに、選択した商店を実行します。 |
| 毎日 | ゲーム内の 1 日につき成功は最大 1 回です。 |
| 毎週 | ISO 週につき成功は最大 1 回です。 |
| 毎月 | ゲーム内の 1 か月につき成功は最大 1 回です。新しく追加したタスクの既定値です。 |

ゲーム内の日付は現在のクライアントのタイムゾーンで計算し、午前 4 時を 1 日の開始とします。毎週はゲーム内日付の ISO 週を比較します。毎月はゲーム内日付の年と月を比較します。

前回成功時刻はその商店の実行が成功したときだけ更新します。失敗または途中停止では更新しません。ミニゲームから同じ商店を手動で購入しても、ワンクリック周回の記録は更新しません。間隔に達していない商店はスキップします。選択した商店がすべて未到達のとき、または何も選択していないときは、タスク全体をスキップしてキューの続きを実行します。
