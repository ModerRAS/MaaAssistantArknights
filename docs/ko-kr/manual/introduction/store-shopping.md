# 상점 구매

::: info UI 전용 기능
이 페이지의 기능은 UI 계층에서 구현됩니다. 자세한 내용은 [초보자 가이드](../newbie.md#이-문서에-대해)를 참고하세요.
:::

상점 구매 작업은 초록 티켓 상점과 노란 티켓 상점을 원클릭 파밍 대기열에 넣고, 실행 간격에 따라 자동으로 구매합니다. 구매 범위는 [미니게임](./tools.md#미니게임)의 해당 기능과 같습니다. 이 작업은 [크레딧 상점](./credit.md)과 별개입니다.

## 상점

동시에 선택할 수 있으며, 초록 티켓 상점, 노란 티켓 상점 순서로 실행합니다.

### 초록 티켓 상점

- 1층은 전부 구매합니다.
- 2층은 헤드헌팅 허가증과 모집 허가증을 구매합니다.

### 노란 티켓 상점

노란 티켓이 최소 258장 있는지 확인하세요.

## 실행 간격

작업 하나가 간격을 공유합니다. 상점마다 마지막 성공 시각을 기록하고 설정에 표시합니다.

| 옵션 | 설명 |
| :--- | :--- |
| 매번 | 작업 대기열을 실행할 때마다 선택한 상점을 실행합니다. |
| 매일 | 게임 내 하루당 성공은 최대 한 번입니다. |
| 매주 | ISO 주당 성공은 최대 한 번입니다. |
| 매월 | 게임 내 한 달당 성공은 최대 한 번입니다. 새로 추가한 작업의 기본값입니다. |

게임 내 날짜는 현재 클라이언트 시간대로 계산하며, 오전 4시를 하루의 시작으로 봅니다. 매주는 게임 내 날짜의 ISO 주를 비교합니다. 매월은 게임 내 날짜의 연도와 월을 비교합니다.

마지막 성공 시각은 해당 상점 실행이 성공한 뒤에만 갱신합니다. 실패하거나 도중에 중지하면 갱신하지 않습니다. 미니게임에서 같은 상점을 수동으로 구매해도 원클릭 파밍의 기록은 갱신하지 않습니다. 간격에 도달하지 않은 상점은 건너뜁니다. 선택한 상점이 모두 도달하지 않았거나 아무것도 선택하지 않았으면 작업 전체를 건너뛰고 대기열의 다음 작업을 계속합니다.
