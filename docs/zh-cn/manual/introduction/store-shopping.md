# 商店购物

::: info UI 专属功能
本页功能由 UI 层实现，详见[新手上路](../newbie.md#关于本文档)中的说明。
:::

商店购物任务把绿票商店和黄票商店放进一键长草队列，按触发间隔自动购买。购买范围与 [牛杂](./tools.md#牛杂) 中的对应功能相同。本任务与 [信用收支](./credit.md) 相互独立。

## 商店

可同时勾选，按绿票商店、黄票商店的顺序执行。

### 绿票商店

- 1 层全买。
- 2 层买寻访凭证和招聘许可。

### 黄票商店

请确保至少有 258 张黄票。

## 触发间隔

一条任务共用一个间隔。每个商店单独记录上次成功时间，并在设置里显示。

| 选项 | 说明 |
| :--- | :--- |
| 每次 | 每次运行任务队列时都执行已勾选的商店。 |
| 每天 | 每个游戏日最多成功执行一次。 |
| 每周 | 每个 ISO 周最多成功执行一次。 |
| 每月 | 每个游戏月最多成功执行一次。新添加的任务默认使用此项。 |

游戏日按当前客户端时区计算，凌晨 4 点作为一天的开始。每周比较游戏日所在的 ISO 周。每月比较游戏日的年与月。

只在该商店本次执行成功后更新上次成功时间。执行失败或中途停止时不更新。在牛杂里手动购买同一个商店，也不更新一键长草里的记录。某个商店未到间隔时会跳过该商店；勾选的商店都未到间隔，或一个都没勾选时，跳过整条任务并继续队列中的后续任务。
