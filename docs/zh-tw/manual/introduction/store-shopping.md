# 商店購物

::: info UI 專屬功能
本頁功能由 UI 層實作，詳見[新手上路](../newbie.md#關於本文檔)中的說明。
:::

商店購物任務把綠票商店和黃票商店放進一鍵長草佇列，按觸發間隔自動購買。購買範圍與 [牛雜](./tools.md#牛雜) 中的對應功能相同。本任務與 [獲取信用及購物](./credit.md) 相互獨立。

## 商店

可同時勾選，按綠票商店、黃票商店的順序執行。

### 綠票商店

- 1 層全買。
- 2 層買尋訪憑證和招聘許可。

### 黃票商店

請確保至少有 258 張黃票。

## 觸發間隔

一條任務共用一個間隔。每個商店單獨記錄上次成功時間，並在設定裡顯示。

| 選項 | 說明 |
| :--- | :--- |
| 每次 | 每次執行任務佇列時都執行已勾選的商店。 |
| 每天 | 每個遊戲日最多成功執行一次。 |
| 每週 | 每個 ISO 週最多成功執行一次。 |
| 每月 | 每個遊戲月最多成功執行一次。新新增的任務預設使用此項。 |

遊戲日按目前用戶端時區計算，凌晨 4 點作為一天的開始。每週比較遊戲日所在的 ISO 週。每月比較遊戲日的年與月。

只在該商店本次執行成功後更新上次成功時間。執行失敗或中途停止時不更新。在牛雜裡手動購買同一個商店，也不更新一鍵長草裡的記錄。某個商店未到間隔時會跳過該商店；勾選的商店都未到間隔，或一個都沒勾選時，跳過整條任務並繼續佇列中的後續任務。
